# 素材入库（ingest）

## 支持格式

| 格式 | 处理 | 说明 |
|---|---|---|
| `.md` / `.txt` | 直接读取为正文 | 文本类不复制原件，避免重复 |
| `.html` / `.htm` | 去标签转纯文本 | 脚本/样式会被移除，保留段落结构 |
| `.pdf` | 有 `pypdf` 时抽取文本 | 无 pypdf 时仍归档，正文留空并提示 |
| 其他 | 仅归档原件 | 视频、仓库导出等先自行转字幕/README |

## 命令

```powershell
python 90_Meta\scripts\kb.py ingest "路径\文件.pdf" --title "自定义标题"
```

产物：

- `10_Raw/YYYYMMDD-标题.md`：素材笔记（`type: source`，含 sha256）；
- `10_Raw/assets/`：非文本原件副本；
- 原文件移动到 `00_Inbox/`（`--keep` 可保留原位）。

## PDF 正文提取

本机没有装 `pypdf` 时：

```powershell
python -m pip install pypdf
```

需要**带边界框**的解析（能定位到页面坐标，便于审阅时回溯）时，建议在库外单独跑一个转换器，把结果写成 Markdown，再放进 `00_Inbox/` 用 `ingest` 登记。坐标信息写进素材笔记的「边界框/页码信息」一节即可，不必进 frontmatter。

> 不要为了解析 PDF 把重型依赖装进本库脚本。`kb.py` 只依赖标准库；转换器是外部工具，产物通过 `00_Inbox/` 进入。

## 大文件与版权

- 单文件 > 20 MB：只登记元数据 + 链接，正文另存摘要。
- 版权敏感内容：素材留在 `10_Raw/`（不发布），卡片里只写你自己的断言，不整段转录。
- 同一素材重复入库：`sha256` 相同会被你看到，直接删掉后一份即可。

## 素材的生命周期

```
new ──拆卡──▶ extracted ──全部卡片确认──▶ processed
```

`lint` 的 I003 会列出「尚未被任何卡片引用」的素材。长期未拆卡的素材，要么安排拆卡，要么在标题前加 `[存档]` 并接受它永远不产出卡片。
