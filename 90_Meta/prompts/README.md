# 提示词

把对应文件的内容整段贴给 AI，替换 `<尖括号>` 里的占位符。所有提示词都以 `AGENTS.md` 为前提；如果 AI 没读过，让它先读。

| 场景 | 文件 | 产出落在 |
|---|---|---|
| 素材拆卡 | `01-拆卡.md` | `20_Staging/` |
| 整理专题内部 | `02-维护MOC.md` | `40_MOC/` |
| 处理审阅意见 | `03-处理audit.md` | 目标笔记 + `70_Audit/` |
| 提专题候选 | `04-提候选.md` | `60_Candidates/` |

一条通用规则：每次结束都让 AI 跑 `python 90_Meta\scripts\kb.py lint --strict` 并贴出结果。
